# Git 용어집

연습하면서 직접 채워나가는 용어 정리입니다.

| 용어 | 뜻 |
| --- | --- |
| 저장소(repository) | 프로젝트의 파일과 모든 변경 기록이 담긴 공간 |
| 커밋(commit) | 변경 내용을 기록으로 남기는 단위. 되돌릴 수 있는 최소 지점 |
| 브랜치(branch) | 작업을 분리하는 독립된 작업 줄기 |
| HEAD | 지금 내가 있는 위치를 가리키는 포인터 |
